# Security and privacy

This project injects a D3D11 wrapper into a local game process. Only download builds from repository releases you trust, and verify published hashes when available.

Diagnostic logs may contain hardware, runtime, executable-hash, and local path information. Review logs before attaching them to a public issue. Process crash dumps can contain fragments of process memory and should not be posted publicly without inspection.

For a security issue that should not be public, use GitHub's private vulnerability reporting feature if it is enabled for the repository. Do not include copyrighted game files or personal tokens in a report.
